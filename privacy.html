Privacy policy

Last updated: 26 September 2026

career-ops is a personal tool used only by its owner, K Aditya Satya Prakash. It is not offered to the public.

Data accessed

  • With the owner's permission, the app uses the Gmail read-only scope (gmail.readonly) to read LinkedIn job-alert emails in the owner's own inbox.
  • From those emails it reads only the subject line and the job links.

How data is used and stored

  • Job links are saved to a local file on the owner's own computer and used only to track the owner's job search.
  • The app never sends, deletes, or modifies email.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.
  • Access tokens are stored only on the owner's computer.

Google API Services User Data Policy

career-ops's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
